Capstone · Hypothesis H3 · Volunteer run-sheet

H3 session guide

Two people place the same kind of replenishment order twenty times: ten the way most MRO stores do it today (a spreadsheet and e-mail), ten in Avilo. The timer screen records how long each order takes, from the moment the order card is handed over until the part is back on the shelf, serviceable.

2 people3 devices≈ 3 hours on the day10 matched pairs of ordersPass mark: Avilo ≥ 30% faster

What you need

  • Laptop for Person A with Chrome and 2 Chrome profiles: Planner, Compliance.
  • Laptop for Person B with Chrome and 4 Chrome profiles: Procurement, Stores, Halcyon, Kestrel. (Chrome: profile picture at the top right → Add → Continue without an account → name it.)
  • Timer device (a tablet, phone or third laptop) placed between you, signed in to Avilo as the Admin, open on H3 session. Anyone may tap it.
  • Each person's own e-mail, open on their laptop, for the manual method. Exchange addresses before you start.
  • The manual workbook for Set A (H3_manual_workbook_Set_A.xlsx) uploaded once to Excel Online or Google Sheets and shared so you both edit the same copy. Also upload Set B for the practice round.
  • The Admin login for Avilo (admin@avilo.test) and the existing Procurement Manager login (procurement@avilo.test). Their passwords were given to you privately; they are not in this guide.
Before the day

Check whether your university needs ethics approval for a session with volunteers, and have both volunteers sign a consent form. No personal data is recorded: Avilo only stores the role accounts and the timings.

Part 2 · How one order runs

Each order starts the same way: Person A taps Start · hand over card on the timer screen and reads the card aloud. The card names the part, the station and the supplier. Always buy from that supplier; never transfer stock between stations.

Manual method (spreadsheet + e-mail)

  1. A Planner finds the part and station on the Stock sheet. Quantity = Order up to − On hand (at least 1). Fill the next line of Purchase orders.
  2. A If the value says YES (USD 5,000 or more), e-mail B for approval; B replies “Approved”. Below 5,000 the Planner's own approval is enough.
  3. Whoever gave the final approval taps Order fully approved.
  4. A E-mails the order to the supplier. B replies “Confirmed, delivery by [date]” and taps Supplier confirmed.
  5. B As Stores: add a line to Goods received with any certificate number (e.g. FORM1-1234), add the quantity to On hand, tap Delivery received, and e-mail A to inspect it.
  6. A As Compliance: check the certificate number in the e-mail matches the Goods received line, fill a line in Certificates, tap Released serviceable. Done.

E-mail templates are on the workbook's “Read me” sheet.

Avilo

  1. A Planner profile → Replenishment. Find the card for that part and station (the quantity is already worked out) and press Approve.
  2. B If it shows a second approval step: Procurement profile → Replenishment → Approve.
  3. B Halcyon or Kestrel profile (the bell shows the new order) → My orders → choose a delivery date → Confirm order → Upload Form 1 → Mark shipped.
  4. B Stores profile → Stores → pick the station at the top → under “Work for …” press Receive.
  5. A Compliance profile → Quality → Verify the delivered part. Done.

Nobody taps the timer after Start: Avilo records approval, confirmation, receipt and release itself.

Part 3 · Practice (≈ 20 min, not counted)

  1. On the timer screen set Session name to Practice.
  2. Manual practice: choose Manual and Set B, open the Set B workbook, and run order 10 all the way through.
  3. Avilo practice: choose Avilo and Set A, press Prepare database for Set A → Reset and prepare, wait about 10 seconds, then run order 10 all the way through.
  4. Talk through anything that confused you. From here on, nobody explains or helps across roles.

Part 4 · The timed session (≈ 90 min)

Set Session name to Team 1 and keep it for all four blocks. The order of the blocks (manual, Avilo, Avilo, manual) spreads the learning effect evenly over both methods.

Block 1
Manual · Set A · orders 1 to 5. Use the Set A workbook. One order at a time: start the next card only after the previous one is released serviceable.
Break
5 minutes.
Block 2
Avilo · Set B · orders 1 to 5. First choose Avilo and Set B and press Prepare database for Set B → Reset and prepare (this clears the practice data). Wait until the Planner's Replenishment page shows 10 cards, then begin.
Block 3
Avilo · Set B · orders 6 to 10. Do not prepare again.
Break
5 minutes.
Block 4
Manual · Set A · orders 6 to 10. Switch the timer back to Manual and Set A.
Rules during the clock
  • One order at a time. The timer screen warns you if two are running.
  • The clock never stops for mistakes. If something goes wrong (wrong quantity, missed approval, sheet not updated), fix it, carry on, and tap Note a problem with a few words.
  • Use Void only if an order truly cannot be finished (for example the internet drops). Then start that same order again.
  • Do not open Avilo during manual blocks, or the spreadsheet during Avilo blocks.

Part 5 · Finish

  1. On the timer screen, scroll to Results and choose Team 1. It shows each pair, the reduction and whether the pass mark was met.
  2. Press Export orders CSV and Export raw log. Download the shared workbook as .xlsx.
  3. Send the three files back for analysis, with a note of anything unusual that happened.
  4. Optional: each volunteer writes two sentences on which method felt easier and why.

How the result is judged

Time to replenish runs from card handed over to released serviceable. Approval to supplier confirmation runs from the final approval to the supplier's confirmation. Order n of Set A and order n of Set B are a matched pair: the same supplier, the same kind of part and the same approval path (orders 1 to 5 are rotables of USD 5,000 or more and need both approvers; 6 to 10 are consumables below the limit).

H3 is supported if Avilo's average time to replenish is at least 30% shorter than the manual method's, and the 95% confidence interval of the paired difference lies entirely below zero. This rule is fixed before the session and is not changed afterwards.

Limits to report: one team gives ten pairs, so the interval will be wide; two people play several roles each; real shipping time is excluded in both methods. If you can, run a second session on another day with Persons A and B swapped and the sets swapped (manual Set B, Avilo Set A) under the name Team 2; that doubles the evidence.
